# MiMo Skills for OpenClaw

米灵灵专属技能包，基于小米 MiMo 模型。

## 技能列表

### mimo-omni — 多模态理解
- 图片分析：描述、OCR、物体识别、场景理解
- 视频分析：内容描述、动作识别、摘要
- 音频分析：语音转录、说话人区分

### mimo-tts-wav — 语音合成
- 文字转语音
- 支持多种风格和声音克隆
- 输出 WAV 文件

## 安装方法

```bash
cp -r skills/mimo-omni ~/.openclaw/skills/
cp -r skills/mimo-tts-wav ~/.openclaw/skills/
```
